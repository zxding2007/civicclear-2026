## Must-do before recording

1. Load the website and let the free host wake, then rehearse case selection and scroll positions. Keep browser zoom at roughly 100–110% and text legible at 1080p.
2. Record the **actual browser** with OBS / Windows Game Bar / QuickTime or similar. Capture mouse clicks on status and evidence source. Use real voice or legitimate captions; no synthesized "live demo" that misrepresents API operation.
3. If the site visibly has a newer public consultation date than November 30, re-check the City official page and update the script before recording.
4. Avoid showing login cookies, API keys, user account details, names of community correspondents, or private tabs. Screen-share browser tab only if possible.
5. Export standard MP4 H.264, replay from the start, verify sound and that total duration is **under 3 minutes**. Upload an unlisted/public accessible link to Devpost.
6. Do **not** claim live Claude API calls, comprehensive impact forecasts or independent municipal sign-off. They are not demonstrated by the cached public view.
