# CivicClear - Municipal Readiness Report
**CIVIC Hack 2026 | City of Toronto pilot | Updated November 13, 2026 | One-page submission companion**

**Who uses it and why.** Residents can browse municipal agenda items, distinguish proposals from adopted decisions, see wards named in official records, and follow source-linked participation instructions. A ward not being listed does not rule out indirect effects. Toronto Clerk's Office, engagement and communications teams are possible stewards; no City endorsement is claimed.

**Application and deployment.** The current revision has six separate pages: overview, decisions, decision details, tax calculator, sources/method and protected record analysis. FastAPI serves the pages and connects them to the existing Python verification and calculator modules. GitHub Pages uses bundled data and a browser calculator; it cannot run Python or live analysis. The previous Streamlit interface remains available. This revision is locally checked and prepared for publication; the public URLs below may still show the earlier versions until deployed.

**Data and AI provenance.** Four pre-generated demo cards use curated public Toronto records. Opening them makes no paid model requests. Automated quote and status checks are distinct from independent human source review, which remains pending. Password-protected analysis supports Claude or DeepSeek and is tested with mocked responses; neither provider has received a real paid test request in this work. DeepSeek uses locally extracted PDF text and model-written quotations checked against the named source, rather than native Claude citations. Its output is an unreviewed preview and is not saved to the demo records.

**Privacy, operations and costs.** Browsing requires no name or street address. Pasted agenda text has named Communications/Speakers sections removed; uploaded PDFs are not redacted. Do not send sensitive material to the model. Cached views incur no LLM inference cost; optional analysis is metered. The Render configuration selects its free plan, subject to provider limits, but no current hosting-cost guarantee or measured model bill is claimed. A municipal pilot needs a reviewer, update monitoring, a budget cap, privacy/security assessment and approved hosting.

**Resident-facing limits.** Official records govern; this is informational, not legal, planning or tax advice. Quotes can omit context and stakeholder impacts are discussion prompts, not measured predictions. Little Jamaica's committee action is distinct from final Council adoption; a separate City portal advertises map feedback through November 30, 2026 (source check: November 12). Recheck dates before use. The tax comparison holds MPAC assessment constant, includes the City Building Fund and excludes education tax; it is not an actual household bill change. Both rates link to enacted tax levy by-laws.

**Validation and next pilot steps.** The revision passes 129 Python tests, including mocked API tests. Targeted browser checks cover navigation, filtering, connected/static calculations, invalid inputs, keyboard use and a 375px mobile layout. These checks do not establish full accessibility compliance. Screen-reader, multilingual and community testing, complete source/PDF review, real API smoke testing and independent human sign-off remain outstanding. Other cities would need locally validated records, procedure vocabulary, participation links and tax tables.
